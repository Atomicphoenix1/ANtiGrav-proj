# AutoUpload: AI-Powered Audio Transcription & Formatting Pipeline

Welcome to the `AutoUpload` directory. This folder contains a comprehensive, multi-stage AI pipeline designed to process raw Arabic audio (lectures, lessons, etc.) into highly formatted, timestamp-aligned, and perfectly styled Microsoft Word (`.docx`) and SubRip (`.srt`) files.

This directory acts as a complete toolkit utilizing `faster-whisper`, LLMs (Google Gemini, Alibaba DashScope), custom timestamp alignment algorithms, and deep XML manipulation.

---

## 🌟 The Core Pipeline

**IMPORTANT:** The primary, most polished, and mechanically complete script in this directory is **`Super-Uploader_BACKUP.py`**.
*Despite the `_BACKUP` suffix, this is the main engine of the project.*

### `Super-Uploader_BACKUP.py`
This script orchestrates the entire workflow through a Gradio Web UI. The pipeline executes the following stages:
1. **Audio Splitting:** Uses `ffmpeg` to split large `.mp3` files into manageable chunks (e.g., 10-minute segments).
2. **Transcription:** Transcribes the audio chunks locally using `faster_whisper`, generating highly accurate Arabic text and word-level timestamps.
3. **LLM Formatting:** Feeds the raw Whisper text to an LLM (typically Google Gemini) to fix punctuation, grammar, and apply proper Arabic styling and structuring.
4. **Timestamp Alignment:** Uses a custom token-anchored alignment algorithm to map the original Whisper word-level timestamps back onto the newly formatted (and altered) LLM text.
5. **Output Generation:** Produces aligned `.srt` subtitle files, `.json` timestamp logs, and highly formatted text.

*Other variants like `Super-Uploader.py`, `Super-Uploader - Copy.py`, `Super-Uploader - Copy (2).py`, and `Super-Uploader-Alibaba.py` (which includes DashScope integration) exist as experimental branches or older iterations.*

## 🛠️ Standalone Utilities

These scripts are extracted components of the main pipeline, designed for independent, targeted use via CLI or lightweight Gradio GUIs.

*   **`testwhisp.py`**: A standalone Whisper transcription tool. It handles audio transcription locally using `faster_whisper` without triggering the rest of the formatting pipeline.
*   **`testgem.py`**: A standalone text-formatting tool. It takes raw text and existing timestamp data (`.srt` or `.json`), passes the text to the Gemini API for punctuation/formatting, and realigns the new text with the old timestamps.
*   **`textsplit.py`**: A standalone utility using `ffmpeg` to split large `.mp3` files into smaller segments (e.g., 10-minute chunks) prior to processing.

## 🔬 Audio & Model Analysis

*   **`Ar_VS_X.py`**: A specialized diagnostic script used to run side-by-side comparisons between a Fine-Tuned Arabic Whisper model (`dev-ahmedhany/whisper-large-v3-arabic-ft-v3-ct2-int8`) and `WhisperX`. It includes aggressive VRAM management (garbage collection and CUDA cache clearing) to allow heavy models to run sequentially on the same GPU.

## 📄 Document (DOCX & PDF) Processing

A suite of tools dedicated to the deep manipulation of document structures and styles. The pipeline ultimately aims to generate perfectly styled `.docx` output.

*   **`extractor.py`**: Unzips a `.docx` file and dumps its entire internal XML structure into a single, readable text file (e.g., `COMPLETE_AI_DUMP.txt`).
*   **`recreator.py`**: The reverse of the extractor. It takes an XML text dump and reconstructs it back into a valid, working `.docx` file.
*   **`v2_formatter.py`**: A script that surgically manipulates `.docx` XML using `python-docx`. It ensures specific standard and Complex Script (Arabic) font properties are properly injected based on predefined XML templates. It also includes an `n8n` webhook trigger.
*   **`fasils.py`**: Contains hardcoded XML string templates (`TYPE_A_XML`, `TYPE_B_XML`) used as injection payloads by `v2_formatter.py`.
*   **`convertor.py`**: A PyMuPDF (`fitz`) utility that scans a provided PDF file and extracts a list of all unique embedded fonts.

## 📂 Artifacts and Data Directories

*   **`amr21/`**: An example output directory demonstrating the artifacts generated by a successful pipeline run (contains `.srt`, `.json` timestamps, and execution logs).
*   **`template/`**: An unzipped DOCX structure folder used as the baseline template for rebuilding Word documents.
*   **`n8n_live_logs.txt`**: The active log file written to by the pipeline scripts to stream status updates.
*   **Misc Text Files (`COMPLETE_AI_DUMP.txt`, `gemmerge.txt`, `الضيافة.txt`, `sample.md`)**: Various XML dumps, sample transcripts, and testing data for the formatting models.
