# n8nion: Published Workflows

This directory contains the **standard JSON exports** for the n8n workflows utilized across the ANtiGrav automation suite.

## 📂 Included Workflows
- **`المواعيد.json`**: The deterministic logic engine for the Scheduling & Personnel Automation project.
- **`send docpdf.json`**: The distribution and human-approval workflow for the Transcription suite.
- **Other Utility Workflows**: Various RSS and notification management exports.

## 🛠️ Usage
These files can be imported directly into any n8n instance to replicate the automation logic described in the project READMEs.
