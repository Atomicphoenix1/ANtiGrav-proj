# Python Aesthetic Snake Game

## Overview
A fully-functional Snake game developed in Python, focusing on custom aesthetics and interactive gameplay modes.

## Features
- **Dynamic Color Palettes**: Visually appealing themes.
- **Multiple Game Modes**: Various difficulty and speed settings.
- **Clean Codebase**: Developed as part of a Python fundamentals course to explore game logic and state management.

## Tech Stack
- **Python** (Turtle/Pygame logic)
- **JSON**: High-score persistence.
