# Personnel Scheduling Automation

## Overview
This project solves the complex problem of coordinating time slots for multiple participants. By connecting Google Forms data to an HTML-based visual interface via **n8n**, this tool allows for rapid filtering and selection of optimal meeting times.

## Impact
- **95%+ Efficiency Gain**: Reduced coordination time from 45 minutes to less than 2 minutes.
- **Visual UI**: Interactive HTML interface to filter participants and visualize density.
- **Automated Recommendations**: Highlights the top 4 time slots where the most participants are available.

## Tech Stack
- **n8n**: Workflow automation.
- **HTML/CSS**: Frontend visualization.
- **Google Sheets**: Backend data storage.
